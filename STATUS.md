## Открытая проверка macOS

В этой Component-сборке обнаружен сбой сетевого процесса: `DCHECK` в
`net/socket/socket_posix.cc`, внутри `SocketPosix::DoConnect`. Он воспроизводится
при прямом запуске и через macOS LaunchServices с новым профилем.
Локальное видео и PiP работают; успешная работа с онлайн-видео пока не подтверждена.
Причина сетевого сбоя ещё не установлена. В PiP-патче сетевой код не меняется.

Обычный запуск приложения из Documents дополнительно запрашивает разрешение macOS
на чтение этой папки. Для проверки LaunchServices использована временная копия
приложения вне Documents. Эти проверки не являются подтверждением работы на Windows.
