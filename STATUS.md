# Состояние проекта

Проверка выполняется на macOS arm64. Windows-сборка в этом окружении не запускалась.

| Этап | Статус |
|---|---|
| Закрепление Brave/Chromium | Готово: версии в `upstream.json` |
| Установка npm-зависимостей | Пройдена на macOS после точечного исправления конфигурации Leo |
| Загрузка Chromium и его зависимостей | Завершена на macOS arm64 |
| Python-проверки подготовки проекта | 9 тестов пройдены |
| Предварительная проверка C++ | Класс PiP и код 8 тестов прошли проверку компилятором с `-fsyntax-only` |
| Нативная компиляция браузера | Базовая сборка продолжается с 6 параллельными задачами; установлен недостающий Metal Toolchain |
| Нативные тесты PiP | Написаны 8 тестов, пока не запускались |
| Проверка интерфейса на реальном видео | Пока не выполнена |
| Установщик Windows | Команда подготовлена, сборка пока не проверена |

До завершения нативной компиляции это исходники для проверки, а не готовый браузер.
